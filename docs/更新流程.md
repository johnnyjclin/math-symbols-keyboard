# 從 symbols.docx 更新鍵盤內容

這支鍵盤的符號清單是一本會持續修改的「字典」，**唯一真實來源就是 `symbols.docx`**。
每當有新版 docx，照下面流程把鍵盤同步成 docx 的內容即可（符號、中文說明、字型、大小全部以 docx 為準）。

> 給 AI 助理：使用者丟一份新的 `symbols.docx`（通常在 `~/Downloads/`）時，直接照本流程更新 `src/MathKeyboard.java` 的 `categories()`，不用再確認是否要保留格式——保留字型/大小是既定需求。

## docx 的結構約定

- 每個 **【分頁標題】** 對應鍵盤的一個分頁（tab）。
- 標題下方一個表格，**第一欄＝符號、第二欄＝中文說明**，每列一個符號。
- 符號的字型/大小就是它在 Word 裡的字型與大小：
  - 字型取 run 的 `w:ascii`（西文）或 `w:eastAsia`（中文字型，如 新細明體）。
  - 大小取 `w:sz`，單位是**半點**，所以要除以 2 才是 pt（`24→12pt`、`28→14pt`、`32→16pt`）。缺 `w:sz` 預設 **12pt**。

## 抽取步驟

1. 解壓 docx 到暫存目錄：
   ```bash
   mkdir -p /tmp/symbols_extract && unzip -o ~/Downloads/symbols.docx -d /tmp/symbols_extract
   ```
2. 解析 `/tmp/symbols_extract/word/document.xml`，依分頁分組，逐列抓「符號 + 說明 + 字型 + 大小」。
   （參考 `tools/extract_symbols.py`，會印出每個符號的 font 與 size。）

## 寫回程式

把抽到的資料填進 `src/MathKeyboard.java` 的 `categories()`，每筆格式為：

```java
{符號, 中文說明, 字型, 大小pt}   // 例：{"∫", "積分", "Cambria Math", "16"}
```

- 按鈕顯示符號、tooltip 顯示說明與字型大小。
- 貼上時會把帶該字型/大小的 HTML 放進剪貼簿，Word / Google Docs 貼上即保留格式。

## 驗證與發佈

```bash
# 編譯驗證（本機 mac 用 brew 裝的 openjdk）
export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"
javac -encoding UTF-8 -d /tmp/out src/MathKeyboard.java

# 沒問題就 commit、push，GitHub Actions 會自動打包出新的 Windows exe
git add -A && git commit -m "依新版 symbols.docx 更新符號" && git push
```

push 後到 [Actions](https://github.com/johnnyjclin/math-symbols-keyboard/actions) 等綠勾，下載 **MathKeyboard-windows** 即為新版 exe。
